# flinkstein-updates

Öffentlicher Release-Feed für das CMS **Flinkstein**, ausgeliefert über GitHub Pages unter
https://updates.kallrich.de/flinkstein/stable/release-feed.json

- Inhalt: nur Versionsnummer, Datum und Changelog-Stichpunkte. Kein Code, keine Kundendaten.
- Erzeugt im Haupt-Repo mit `npm run release:feed` und hier hineinkopiert (später per Release-Workflow).
- Installationen fragen anonym ab (höchstens alle 12 Stunden, ohne Installationsdaten).
